1. Run `npm install`
2. Run `npm run dev`

## Novedades (análisis trimestral y mapa)

**Mapa**
- Puntos con colores vivos (ya no blancos): rojo/naranja/amarillo/verde según la prioridad de su zona y celeste para siniestros aislados.
- Selector **Vista**: *Puntos*, *Calor* (mapa de calor ponderado por fallecidos) o *Ambos*.
- Selector **Color de puntos**: por prioridad o por trimestre (T1–T4).
- **Línea de tiempo por trimestres** en la parte inferior: toque un trimestre para verlo en el mapa o pulse *Reproducir* para animar todos los trimestres.
- Mapa base claro por defecto y opción *Oscuro* para resaltar el calor. Leyenda dinámica y plegable.

**Filtros**
- Bloque *Periodo* con año desde/hasta y **filtro por trimestre** (afecta a todas las páginas, incluido el mapa).

**Patrones** (organizado en pestañas)
- Nueva pestaña **Trimestres y tendencias**: tarjetas por trimestre, línea de tiempo trimestral con promedio móvil, gráfico agrupado (mismo trimestre en distintos años), mapa de calor año × trimestre, hallazgos automáticos, **"¿Por qué cambió?"** (qué provincias, tipos, causas, vehículos y horarios explican una subida o bajada) y **proyección del siguiente año** con rango probable.

Instalación: `npm install` y `npm run dev` (se añadió la dependencia `leaflet.heat`).
